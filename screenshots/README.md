# screenshots

存放 README 页面预览截图。运行应用后手动截图（或使用浏览器 DevTools 的设备模拟），按以下命名保存。

## 命名规范

| 文件 | 页面 |
|---|---|
| `home.png` | 首页（仪表盘） |
| `stats.png` | 统计分析 |
| `calendar.png` | 流水日历 |
| `records.png` | 流水管理 |
| `ai-assistant.png` | AI 记账助手 |

## 建议

- 分辨率建议 1440px 宽，PNG 格式
- 深色/浅色主题均可，保持风格统一
- 截图放入后，取消 README.md「页面预览」区对应的注释即可显示
