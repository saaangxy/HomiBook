Docker 部署

两分钟部署到你自己的服务器

拉取仓库、改好环境变量，一条 docker compose up -d 就能跑起来； 数据完全留在自己手里，也可以连接已有的 MySQL / PostgreSQL 实例。

  • 单容器镜像，前端与后端一起启动
  • 默认 SQLite，家庭场景零运维
  • 环境变量切换端口、数据库与密钥
  • 有新的 Release 时应用内自动提示
阅读完整部署指南
Docker Compose（推荐） 
git clone https://github.com/saaangxy/HomiBook.git
cd HomiBook

cp .env.example .env   # 修改端口、JWT 密钥、数据库类型
docker compose up -d

# 打开 http://<服务器IP>:8080
本地开发（需 Node.js 22+） 
# 后端（端口 3002）
cd backend && npm install && npm run dev

# 前端（端口 5173，自动代理 /api）
cd frontend && yarn install && yarn dev

部署前先看看效果

演示站使用临时数据，重启会重置；正式使用请自行部署。
