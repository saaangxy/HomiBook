功能特性

九项能力，把家庭财务管明白

从随手记一笔到年度复盘，从手机拍照到 Docker 自托管，HomiBook 覆盖家庭账本的完整链路。

开源 & 自托管

数据留在自己的服务器，代码完全公开

  • MIT 协议开源
  • 账目存进自己的数据库
  • 单容器镜像，前后端一起部署

安装简单

一条命令起步，家庭服务器零运维

  • 支持 Docker Compose 一键部署
  • SQLite / MySQL / PostgreSQL 可选
  • 环境变量切换端口与数据库
  • 有新的 Release 时应用内提示

友好的界面

手机与桌面都顺手，主题随心换

  • 响应式 Web，手机浏览器同样好用
  • 浅色 / 深色 / 跟随系统
  • 手工杂货铺、旧式电报机等多套主题
  • 移动端 App 与 Web 数据互通

AI 驱动的记账

说一句话、拍一张图就能入账

  • 自然语言生成流水
  • 支付宝 / 微信 / 京东账单导入并自动分类
  • 小票 OCR 与图片内容理解
  • 联网搜索与 AI 记忆

强大的家庭记账

从随手一笔到年度复盘

  • 流水、日历、统计三种视图
  • 分类占比、趋势与财务健康度
  • 预算设定与支出进度监控
  • 固定收支与贷款还款计划

多人协作

一家共用一本账，各记各的也不乱

  • 家庭成员共享账本
  • 管理员与成员角色分离
  • 多账本分类整理不同用途

多账户 · 多币种

钱放在哪、花了多少都清楚

  • 现金、银行卡、微信、支付宝统一管理
  • 支持多币种记账
  • 余额可按指定时间点后重算

数据备份与迁移

换库、换服务器都不丢数据

  • 账本数据完整备份导出 / 导入
  • 支持按模块迁移
  • 导入时重复流水自动检测与合并

移动端体验

不止是把网页装进手机

  • 拍照或从相册选图直接记账
  • Android 短信 / 通知自动入账
  • 系统分享图片直达 AI 对话
  • 连接自托管的 HomiBook 后端
AI 记账助手

说一句话，账就记好了

支持接入 OpenAI / DeepSeek / Anthropic 等兼容协议的模型，配置按账号隔离， 每位家庭成员都能用自己的模型与密钥。

  • 01
    自然语言记账「昨天超市买菜 128」直接生成一笔流水
  • 02
    账单一键导入支付宝 / 微信 / 京东账单导入，AI 自动分类并保存映射规则
  • 03
    小票 OCR 与图片理解拍照或截图入账，看过的图片会被记住，追问不必重传
  • 04
    联网搜索Bing / 百度 / Google 可切换，网页内容抓取辅助分析
  • 05
    操作前确认批量增删改先给预览卡片，看清影响范围再执行
  • 06
    AI 记忆与多分支对话记住你的记账偏好；编辑或重试可生成可切换版本
