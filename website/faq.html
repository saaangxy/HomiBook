常见问题

关于数据、部署与 AI 的疑问

先看看这里有没有答案；没找到的话，欢迎到 GitHub 提 Issue。

HomiBook 的数据存在哪里？会上传到第三方吗？

所有账目数据都保存在你自己部署的数据库里（默认是服务器上的 SQLite 文件，也可以换成 MySQL / PostgreSQL），不经过任何第三方服务。

如果你配置了 AI 助手，对话内容会发送到你选择的模型服务商，具体处理方式以该服务商的隐私政策为准。

支持哪些数据库？怎么切换？

支持 SQLite、MySQL、PostgreSQL。在 .env 中用 DATABASE_PROVIDER 选择数据库类型，DATABASE_URL 填写连接串，重启容器后生效。

切换前建议先导出账本备份，完整步骤见 部署指南。

演示站的账号密码是什么？数据会保留吗？

账号 admin，密码 Ad123456。

演示站是免费实例，SQLite 数据为临时存储，实例重启后会重置，请不要在其中记录真实账目。

怎么导入支付宝、微信、京东的账单？

先在原 App 中申请「用于个人对账」的账单导出，收到文件后到 Web 端「流水 → 导入」上传，或在 AI 助手里选择账单导入。

导入前会显示预览卡片，可以修改分类与账户映射，确认后才写入；映射规则会被保存，下次导入同名字段自动命中。

微信导出的是加密压缩包，需要先解压出 xlsx 文件；支付宝与京东的 CSV 为 GBK 编码，HomiBook 会自动识别，无需手动转码。

AI 助手需要自己准备 API Key 吗？支持哪些模型？

需要。在「设置 → AI 助手」中配置模型供应商（支持 OpenAI / DeepSeek / Anthropic 等兼容协议），在「设置 → API 密钥」中填入密钥。

配置按账号隔离，每位家庭成员可以使用自己的模型与密钥，互不影响。

移动端怎么连接自己部署的后端？

在 App 的「服务器设置」中填入后端地址，例如 http://192.168.1.10:8080（局域网）或你的公网域名。

连接后，Web 端与移动端的账目实时互通；在手机端还可以拍照记账、从系统分享图片直达 AI 对话。

数据会不会丢？怎么备份？

支持整本账目的备份导出与导入，也支持按模块迁移。换数据库、换服务器或升级前，建议先导出一份备份。

导入时系统会自动检测重复流水并合并，导入多次也不会重复记账。

怎么升级到新版本？

重新拉取镜像并重启容器即可，具体步骤与回滚方式见 部署指南。

应用内「设置 → 关于」可以检查是否有新的 Release。

支持多个家庭成员和多个账本吗？

支持。家庭成员可以共享同一本账，区分管理员与成员角色；也可以建立多个账本，分别记录不同用途的账目。

每个账号的 AI 配置独立，家庭成员的模型与密钥互不干扰。

部署需要什么样的服务器？

单容器镜像，默认使用 SQLite，资源占用很小，家庭服务器或 NAS 都能跑。对外访问需要开放容器端口（默认 8080）。

具体环境变量与配置项见 部署指南。
